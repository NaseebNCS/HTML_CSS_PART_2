POSITIONING ELEMENTS

Going forward in this lecture, we are going to cover various techniques for positioning elements. We will learn how to precisely position elements. 

.boxes{
        border: 3px solid lightgrey;
}

.box{
        width: 5rem; 
        height: 5rem; 
}

.box-one{
        background: gold;
}

.box-two{
        background: red;
}

.box-three{
        background: black;
}

Here, we have created a very basic layout where the .boxes container holds three boxes. Each box has a separate class, such as box-one to box-three, and all boxes also share the common class box. Now, if we want to move these boxes from their original positions, we use a concept called positioning.

RELATIVE

.boxes{
        border: 3px solid lightgrey;
}

.box{
        width: 5rem; 
        height: 5rem; 
}

.box-one{
        background: gold;
}

.box-two{
        background: red;
        position: static; /* Static is Default value */
}

.box-three{
        background: black;
        position: relative; /* Relative to Its Original Position */
        left: 5rem; /* 5rem gap from left */
}

position: relative means the box or element is positioned relative to its normal place. However, we can move it left, right, top, or bottom, and adjust its z-index. We can also use negative values for these properties. By default, each element has a z-index value of 0. 

    .box-one{
        background: gold;
        position: relative; 
        right: 4rem; /* same as -4 from left */
        top: 2rem; /* 2rem space from top */
}

The other boxes are in their original positions as they are supposed to be. They are not affected by the positioning of the sibling elements.

Z-INDEX

.box-one{
        background: gold;
}

.box-two{
        background: red;
        position: relative;
        left: 4rem;
        bottom: 4rem;
        z-index: -1; /* send backward */
}

.box-three{
        background: black;
}

On a web page, there are three axes: the horizontal axis (or X-axis), the vertical axis (or Y-axis), and the Z-axis, which represents depth. We can imagine the Z-index like light coming from the device toward our eyes. By default, each element has a Z-index value of 0. If we increase the value (e.g., 1, 2), the element appears closer to us. If we use negative values (e.g., -1, -2), it moves farther away or behind other HTML elements.

ABSOLUTE

With relative positioning, we can move an element relative to its normal position. This will not impact other elements on the page. In contrast, with absolute positioning, we can move an element relative to its container or parent element. 

.boxes{
        border: 3px solid lightgrey;
        position: relative; /* absolute position will work based on this relative position */
}

.box{
        width: 5rem; 
        height: 5rem; 
}
 
.box-one{
        background: gold;
}

.box-two{
        background: red;
        position: absolute; /* position it self according to the parent who has position relative. */
        right: 0;
        bottom: 0;
}

.box-three{
        background: black;
}

If we want child elements to be positioned relative to their main container or parent container, the parent must have position: relative. This way, the child will be positioned based on its parent, which has relative positioning.

When we set an element’s position to absolute, it is removed from its normal position in the document flow, and the next elements take its place. From the parent’s point of view, the element with position: absolute does not exist. We can imagine it as being on a separate layer.

FIXED

If you want an element to remain fixed in its position, such as a navigation bar or any other element, you can use the position: fixed property. 

.logo{
        width: 100px;
        height: 100px;
        position: fixed;
        right: 10px;
        bottom: 10px;
}

If you increase the content and have an image inside this logo element, you will see that it stays fixed in its given position. We can use left, right, top, bottom, and z-index with any position property except the static value. You can imagine it like the message icon in a WhatsApp chat app, which is fixed at the bottom-right of your mobile viewport. You can scroll through chats, but the icon always remains in the same position.

We can also use these properties to set the width and height of any element by combining the left and right, or the top and bottom. 

  .child-box{
          position: fixed;
          left: 2rem;
          right: 2rem; 
          background: red;
          height: 100px;
  }

The child box doesn't have a width property, but it takes its width from the combination of the left and right properties when using position: fixed.

STICKY

position: sticky means an element stays in its normal place, but when you scroll and it reaches a certain point (like the top), it sticks there.

Think of it like this:
  • A heading or menu is in its normal position.
  • You scroll down.
  • When that element touches the top of the page, it sticks to the top.
  • When you scroll back up, it goes back to its original place. 
.nav-bar{
          position: sticky;
          top: 0;
}

One-line explanation:
➡️ Sticky is a mix of relative and fixed normal at first, then fixed when scrolling. Add content before and after the element who has position: sticky.

We can also use positioning properties to stretch a box or container by setting its width and height using position values.

Using Inset Shorthand

The inset property is a shorthand for:
- top, right, bottom, left
When you set all four, the element stretches automatically. 

.box {
  position: absolute;
  background: tomato;
  inset: 20px;  top:20px; right:20px; bottom:20px; left:20px 
}

CURSOR

The cursor property changes how your mouse pointer looks when it moves over an element. For example, you can show a pointer, text cursor, move icon, or even a custom image. 

img {
        cursor: pointer; Mouse pointer turns into a hand use control + space to see other values.
}

Calc Function

The calc() function lets you do simple math (like +, -, *, /) to set sizes. It helps when you want a mix of different units (%, px, etc.). 

.box {
        width: calc(100% - 50px); Full width minus 50px
}

FORM

Welcome to another section of HTML CSS Part 2! In this section, we will learn everything you need to know about forms including how to build them, style them, and work with different input types such as text fields, dropdown lists, checkboxes, radio buttons, sliders, file inputs, and hidden fields. We will also cover data validation and form submission. Let's start this exciting journey!

Creating a Basic Form

Let's see how to create a basic form. Start with the <form> element and give it an action attribute. The action attribute specifies where the form data will be sent when submitted. A form usually contains one or more fields, also called form controls. Each input field has a type attribute, which defines the kind of input. For example, type="text" creates a single-line text input. Now let's create a simple input field with a label. 

<form action="">
  <p>Name</p>
  <input type="text">
</form>

Lable

If we use a <p> element for the label, it can cause some problems. The first problem is that it creates extra space between the text and the input field, making them look disconnected. We could fix this with CSS, but there is a better solution: use the <label> element.

The <label> element allows you to type the label text and connect it to a specific input field. Each <label> has a for attribute, which should match the id of the input field. This way, when you click the label text, the corresponding input field is focused. Using <label> makes your form more accessible and user-friendly. 

<form>
  <lable for="name">Name</lable>
  <input id="name" type="text">
</form>

Email

If you change the input type to something like email, the browser will provide basic validation. For example, if the user enters an email without the @ symbol, an error will be shown automatically. 

<form>
  <label for="email">Email</label>
  <input id="email" type="email">
</form>

Button

The <button> element is used to create buttons for submitting or resetting a form. You can set the button's behavior using the type attribute. You can also use the <input> element with type="submit" or type="reset" to achieve the same functionality. 

<form>

    <label for="name"> Name </label>
    <input id="name" type="text">
    <label for="email"> Email </label>
    <input id="email" type="email">
    <button type="submit"> Register </button>
    <button type="reset"> Clear </button>

</form>

This is how we style forms. As we move forward in this section, we will have several input fields. Defining styles for each input field can be time-consuming, which is why many developers use CSS frameworks.

CSS Frameworks

As we have seen, styling a form can be a bit time-consuming. This is where CSS frameworks come in handy. A framework is essentially a library of pre-written CSS code that helps us build more beautiful and consistent websites quickly.

There are many frameworks available, such as Bootstrap, Foundation, Semantic UI, UIkit, Materialize, Milligram, and TailwindCSS, and new ones keep coming out all the time. We don’t need to know all of them no developer knows every framework.

Tailwind CSS

Currently, Bootstrap and TailwindCSS are very popular. One thing to keep in mind is that using a framework often includes downloading a lot of extra code we might not need. That’s why some developers prefer writing custom CSS, so they only include the code necessary for their project.

Which approach to use depends on the problem we are solving and sometimes on the company we work for, as they may have already chosen a specific framework for their projects.

Bootstrap

Visit the official Bootstrap website at getbootstrap.com. There are two ways to use Bootstrap in your project:

  1. Download it and add it to your project files.
  2. Use the CDN link (Content Delivery Network) to include it directly in your HTML.

A CDN is a network of servers around the world that delivers web content like images, CSS, and JavaScript files quickly and efficiently.

To use Bootstrap via CDN:

  • Search for the Bootstrap CDN link.
  • Copy the link and paste it inside the <head> section of your HTML document.

Once you include the CDN, you can style your form using only Bootstrap classes. The CDN automatically applies styles based on the classes you use.

Now, let's create a basic HTML form using Bootstrap via CDN, with CSS styling explained.

Explanation of Bootstrap Classes:

  • form-control👉 Styles inputs with padding, borders, and rounded corners.
  • form-label👉 Styles labels for inputs.
  • mb-3👉 Adds margin-bottom to space out form elements.
  • btn btn-primary👉 Creates a primary styled button.
  • d-grid👉 Makes the button take full width.
  • text-center👉 Centers the heading text.

Bootstrap Documentations

Read the Bootstrap documentation to learn more about Bootstrap utility classes. There is a lot of information there, including examples of how to use different components. Bootstrap is a very comprehensive library, but that comes at a cost.

If you go to the page where you used Bootstrap, open the Network tab in the browser's Inspect tool, refresh the page, and filter for CSS files, you will see the Bootstrap files loaded from the CDN. If the file size is around 20 KB, it is quite small and usually not a problem.

However, many websites include lots of images, CSS libraries, and JS libraries, and if you combine all of them, the total size can exceed hundreds of KBs. On a slow internet connection, this can lead to a poor user experience. For most websites, waiting a second or two is acceptable, but for large e-commerce sites like Amazon, even a one-second delay can reduce sales by around 20%.

Milligram

If you don’t need most of the Bootstrap components, you can use a minimalist framework called Milligram. Go to milligram.io , click Get Started, and copy the Milligram CSS link just like you would for Bootstrap.
Once you include Milligram in your HTML, it will automatically style elements like forms without the need to learn many classes or read extensive documentation.

The main advantages of Milligram are:

  • It is 10 times smaller than Bootstrap.
  • It automatically styles elements like form input fields.
  • It is simple and lightweight, perfect for small projects or when you don’t need all of Bootstrap’s features.

By using Milligram, your forms and basic elements will look beautiful without extra effort.

Input Basic Fields

Let's learn about other input fields in HTML and how we can style them using custom CSS, like controlling the width, padding, and more. There are many types of input fields, and changing the type attribute changes how the input behaves.

  • Text input: If type="text", the input accepts text.
  • Number input: If type="number", it accepts only numbers. On desktops, users can use the up/down arrows, and on phones, the numeric keyboard pops up for easier input.

Always test input types in your browser to see how they behave.

  • Textarea: Used for multi-line text input. You can type directly inside it, and the area can be resized by default. To prevent resizing, use CSS: resize: none;.
  • Value attribute: Pre-fills the input field with default text.
  • Placeholder attribute: Shows a label or hint inside the input field. It disappears when the user starts typing.
  • Disabled and readonly attributes: Prevent the user from editing the input or sending its value to the server.
  • Maxlength attribute: Limits the number of characters the user can enter.
  • Autofocus attribute: Automatically focuses on the input field when the page loads, which is useful in login forms so users don’t have to click the field manually.
  • Other input types: Press Ctrl + Space in the type attribute in your code editor to see all available input types.

Note on buttons: Creating a button using <input type="button"> only allows text. If you want a button with an icon or more customization, use the <button> element instead.

    <input type="text">

    <input type="password" placeholder="********">

    <input type="time">

Data List

If you want to show suggestions as a user types in an input field, you can use the datalist element with option elements. To connect the input field to the datalist, give the datalist a unique id and set the input’s list attribute to that id.

For example, if you link a database to the form, you may want to send a numeric value to the server instead of the displayed text. For instance, a database of countries might assign a unique identifier to each country. When the form is submitted, you can send this unique identifier to confirm which country the user selected. You can achieve this by using the value attribute for the options to send the identifier, and optionally using data- attributes to store additional information that is not shown to the user. JavaScript can then read these custom attributes and send them to the server.

If you want to disable the browser’s default autocomplete suggestions (for example, if the user has already typed something and you don’t want extra tooltips), set the input’s autocomplete attribute to off.

Note that every browser has its own default styling for datalists and options, and you cannot fully style them with CSS alone. To create a fully custom-styled suggestions list, you would need to use JavaScript, which is beyond the scope of this HTML course. 

<form>
      Disable Suggestions or Extra Toolkits provided by Browsers Using Autocomplete
      <input type="text" list="countries" autocomplete="off">
      <datalist id="countries">

          Data-Value is a custom attribute
          <option data-value="1">UAE</option>
          <option data-value="2">India</option>
          <option data-value="3">China</option>
          <option data-value="4">Pakistan</option>
          <option data-value="5">Afghanistan</option>

      </datalist>
</form>

Check Boxes

Now, let’s learn how to display checkboxes. Use the <input> element, and you’ll see different types of inputs, including checkboxes. Each checkbox is usually associated with a <label> for better accessibility. If you are still using Milligram, don’t forget to check their documentation for details.

To make a checkbox selected by default, use the checked attribute. This attribute is boolean, which means it can either be present (checked) or absent (not checked). You can also use the disabled attribute to make a checkbox unclickable. 

<form>
    
    <input type="checkbox" id="front-end" checked>  
    <label for="front-end">Front-End</label>

    <input type="checkbox" id="back-end">  
    <label for="back-end">Back-End</label>

</form>

Radio Buttons

Checkboxes allow users to select multiple items. But sometimes, we want the user to select only one option. In such cases, we can use a dropdown list or radio buttons. For radio buttons, the name attribute is used to group multiple buttons so that the user can select only one option from the group. Similar to checkboxes, you can make one radio button selected by default using the checked attribute. 

<form>
      <input type="radio" name="membership" id="silver">
      <label for="silver">Silver</label>

      <input type="radio" name="membership" id="gold">
      <label for="gold">Gold</label>
</form>

Dorp-Down Lists

To create a dropdown list in HTML, we use the <select> element. Inside it, we add <option> elements for each choice. To make an option selected by default, use the selected attribute with the <option> element. To allow users to select multiple options, add the multiple attribute to the <select> element. If there are many options, you can group them using <optgroup>. Each group should have a label to describe the type of options inside.

File Inputs

On web pages, buttons like “Select Documents” or “Upload CV” are created using <input type="file">. To allow multiple file selection, add the multiple attribute. You can also use the accept attribute to restrict the file types, for example, accept=".jpg" will allow only JPG files to be selected. 

<form>

      <input type="file">
      <input type="file" multiple>
      <input type="file" accept=".jpg">
      <input type="file" accept=".jpg, .png, .pdf">

      To Allow user select Vides, Audioes Etc.
      <input type="file" accept="audio/*">

</form>

Hiddent Fields

Suppose we have a form for editing a course, with fields like title, subtitle, price, etc. Sometimes, we want to submit this form to the server.

The server needs to know which course is being submitted. To do this, each course has a unique identifier (ID), usually a number like 1, 2, 3, and so on. These IDs are generated by the server.

When we display the form, we include this course ID so that when the user submits the form, the server knows exactly which course to update. This is where hidden fields come in.

A hidden field is an input field that the user cannot see. Even though it is invisible, its value is sent to the server when the form is submitted. For example, if the hidden field’s value is 1234, the server receives 1234 along with the other form data.

Important: Even though hidden fields are invisible, we should never store sensitive information in them. Anyone can view these values in the page’s source code or using browser developer tools.

In short, hidden fields are used to store non-sensitive data like the course ID, so the server knows which course the user is editing. 

<form>

      <input type="hidden" name="course=id" value="1234">

</form>

Data Validation

Before submitting a form, we should always make sure the data is in the correct format. For required fields, we must confirm that they are filled out. If we want to collect an email, it should be a valid email address, not random characters. For numbers, they should be within a valid range for example, age or price cannot be negative. Dates should also be validated to ensure they are correct.

Validating data before submission is important to prevent data corruption and security issues. Hackers can exploit invalid input by entering negative numbers, extremely long strings, or other incorrect values to break the system.

HTML provides built-in attributes for basic data validation, such as required, min, max, type="email", etc. For more complex validations, JavaScript can be used to check the data before submission.

      Minimum characters 3
      <input type="text" required minlength="3">

      Maximum 10 Characters Supported
      <input type="text" required minlength="3" maxlength="10">

      For Numbers Min & Max is used
      if you don't want to allow negative values, by setting the min to 0 it means the negative values are not supported, it helps to protect data curroption
      <input type="number" required min="0" max="10">
      <button type="submit">SUBMIT</button>

</form>

Submitting The Form

If we want to get data from a user, for example their name, email, and contact number, we need to create a form.

To submit a form, we use the action attribute in the <form> tag, where we provide a relative or absolute URL. This URL tells the form where to send the data.

This is where server-side technologies come in. There are many backend technologies, for example:

  • Node.js / Express – used by JavaScript developers
  • Django – used by Python developers
  • ASP.NET – used by C# developers
  • Laravel – used by PHP developers
  • Ruby on Rails – used by Ruby developers

You don’t need to learn all of them; choose one based on your expertise. But for now, our focus is on frontend, not backend, to keep things simple.

We will use a service called Formspree.io. It provides a ready-to-use backend for your forms. It’s free to use. Here’s how:

  1. Go to Formspree.io and create an account.
  2. Click the “Project” button to create a project.
  3. Inside the project, click “New Form” or “Create Form”.
  4. Give your form a name, like Contact Form.
  5. Click Create. Formspree will generate a backend for you automatically.

Next, copy the URL provided by Formspree and paste it in the action attribute of your form.

Each input field in the form should have a name attribute, because it identifies the data being sent. Also, set the form’s method attribute, which determines how data is sent:

  • POST – sends data in the body of the HTTP request. This is the most common method. You can check it in the browser’s Network tab while submitting the form. You will see a request sent to the server, with the form fields (like name and email) in the request body.
  • GET – sends data by appending it to the URL. This is useful for bookmarks. For example, when you search on Google, the search keyword appears in the URL. You can bookmark that URL and return to it later. 
In action past your own link
<form action="https://formspree.io/f/myybnlqn" method="POST">

    <input type="text" placeholder="Name" required name="Name">
    <input type="email" placeholder="xyz@gmail.com" required name="Email">

</form>

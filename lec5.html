OVERFLOWING

One of the most important concepts we need to understand is that when dealing with fixed-size elements, we may encounter overflow content. If we have a container with a fixed size and the content exceeds the container’s capacity, overflow occurs. It’s similar to a glass: if we pour too much water into it, the water starts to overflow. 

.box{
      width: 100px;
      height: 100px;
      border: 3px solid red; 
}

If we create a paragraph inside this box and give it more text than the box can contain, it will start overflowing. However, we can control the overflow in different ways. 

.box{
      width: 100px;
      height: 100px;
      border: 3px solid red; 
      overflow: visible; /* Default Value */
      overflow: hidden; /* Hides overflow */
      overflow: scroll; /* Enables the Horizontal & Vertical Scroll bar. */
      overflow: auto; /* Enables the Scroll bar when the content starts overflowing. */
}

The overflow property is a shorthand for two properties: overflow-x and overflow-y. When we supply a single value to overflow, it applies to both overflow-x and overflow-y. However, sometimes we may want more control over the overflow in different directions. 

.box{
      overflow: hidden auto; /* overflow-x: is hidden and overflow-y is auto */
}

It depends on the layout which type of overflow we want to control. Overflow is used to manage the content of fixed elements.

SCROLLBAR

Scrollbar Properties (Chrome, Edge, Safari -WebKit)


1. ::-webkit-scrollbar

Controls the overall width/height of the scrollbar.


2. ::-webkit-scrollbar-track

Styles the background track area where the scrollbar thumb moves.


3. ::-webkit-scrollbar-thumb

Styles the draggable thumb that moves inside the track.


4. ::-webkit-scrollbar-thumb:hover

Styles the thumb when the user hovers over it.


5. ::-webkit-scrollbar-button

Styles the up/down or left/right arrow buttons on the scrollbar (rarely used). 


6. ::-webkit-scrollbar-corner

Styles the bottom-right corner where horizontal and vertical scrollbars meet. 


7. ::-webkit-scrollbar-track-piece

Styles the part of the track not covered by the thumb.


8. ::-webkit-scrollbar-thumb:active

Styles the scrollbar thumb when clicked or dragged.


Scrollbar Properties (Firefox)


9. scrollbar-width

Controls the scrollbar thickness (auto, thin, or none).


10. scrollbar-color

Sets the thumb and track colors for Firefox scrollbars.



.my-box {
  width: 300px;
  height: 200px;
  overflow: auto;
}

/* Scrollbar width */
.my-box::-webkit-scrollbar {
  width: 10px;   /* vertical scrollbar */
  height: 10px;  /* horizontal scrollbar */
}

/* Scrollbar Track (background) */
.my-box::-webkit-scrollbar-track {
  background: #f1f1f1;
  border-radius: 5px;
}

/* Scrollbar Thumb (the moving part) */
.my-box::-webkit-scrollbar-thumb {
  background: #888;
  border-radius: 5px;
}

/* Thumb hover */
.my-box::-webkit-scrollbar-thumb:hover {
  background: #555;
}


/* Firefox uses a different syntax: */
.my-box {
  scrollbar-width: thin;          /* auto | thin | none */
  scrollbar-color: #888 #f1f1f1;  /* thumb | track */
}


/* Fully Custom Modern Scrollbar (Cross-Browser) */
 Combine both:
.my-box {
  overflow: auto;

  /* Firefox */
  scrollbar-width: thin;
  scrollbar-color: #555 #e0e0e0;
}

/* Chrome, Edge, Safari */
.my-box::-webkit-scrollbar {
  width: 12px;
}

.my-box::-webkit-scrollbar-track {
  background: #e0e0e0;
}

.my-box::-webkit-scrollbar-thumb {
  background-color: #555;
  border-radius: 20px;
  border: 3px solid #e0e0e0;
}

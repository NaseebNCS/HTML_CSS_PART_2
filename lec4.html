BOX SIZING

The size of an element or box is always dependent on its content Width + Height, the box Padding, and The box Borders.
Height = Height + Padding-Top + Padding-Bottom + Border-Top + Border-Bottom
Same rules are applied for the width.
Margins are out of the box, Margins are not a part of the box sizing. 

.box{
      width: 100px; 
      height: 100px; 
      background-color: red;
}

The actual width and height of the box is now 100px but if we use Borders & Paddings the box size will not remain the same. 

.box{
      width: 100px; 
      height: 100px; 
      background-color: red; 
      padding: 20px; 
      border: 10px solid gold;  
}

By default, the width and height properties are applied to the content box. Any padding or borders will increase the overall size of the visible box. Currently, the actual width of the box is 160px, and the actual height is 160px. The margin does not affect the size of the box; it only moves the box away from other elements or boxes.

As we can see, counting the size of an element is a bit complex, and we can't rely on it all the time. This is where the box-sizing property comes to the rescue. 

.box{
      width: 100px; 
      height: 100px; 
      background-color: red; 
      padding: 20px; 
      border: 10px solid gold;  
      box-sizing: content-box; /* Default Value */
      box-sizing: border-box;  
}

It means that the size we have specified is now part of the border box. The padding and borders no longer occupy separate space outside the box; they are included within the same box width and height. The width and height are now fixed, with the border and padding subtracted from the box dimensions. As a result, the content area is reduced to 40px.

Note: We can't apply the box-sizing: border-box; property to each element individually. Instead, we use the universal selector at the top of the CSS code. The universal selector selects all HTML elements. 

*{
      box-sizing: border-box; 
}

The universal selector won't target the psuedo elements.

In a browser, the Inspect tool has a Styles tab, and within it, you can access the Computed tab to check all the properties of an element.

If we want to target the pseudo-elements ::before and ::after, we can use universal selectors like this: 

*, 
*::before, 
*::after
{
        box-sizing: border-box; 
}

Behaviour

Inline elements don't respect the width and height properties, but we can change their behavior. For example, we can convert a block element to inline, an inline element to block, or an element to inline-block. Elements with inline-block are not forced onto a new line, yet we can apply width and height to them. 

.box{
      width: 100px; 
      height: 100px; 
      background-color: red; 
      display: inline; /* block to inline */ 
      display: block;  /* inline to block */ 
      display: inline-block;   /* inline or block to inline-block */ 
      dispaly: None;           /* hide element */ 
}

If we use more than one property, the last property will be applied to the element. To see the difference between these display types, you can use a <span> or any other inline, block or inline-block elements.

  • Inline elements do not start on a new line and only take up the width of their content.
  • Block elements start on a new line and take the full width available.
  • Inline-block elements don’t start on a new line but they take width and height properties.

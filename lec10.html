HIDING ELEMENTS

let's talk about hiding elements there are two properties used to hide elements, dispay and visibility.

display: none

display: none completely hides the element from the page. It removes the element from the layout, so it does not take any space. 

HTML CODE
<p class="text">This paragraph will hide using display.</p>

CSS CODE
.text {
        display: none;
}

The paragraph becomes invisible and its space disappears.

isibility: hidden

visibility: hidden hides the element but keeps its space reserved in the layout.
The element becomes invisible but still occupies its original area. 

HTML CODE
<p class="text2">This paragraph will hide using visibility.</p>

CSS CODE
.text2 {
        visibility: hidden;
}

The paragraph is invisible, but its empty space still remains.

Multiple ways to hide elements

To hide elements in CSS, we commonly use properties like display: none, visibility: hidden, and opacity: 0. The display: none property completely removes the element from the page, so it doesn’t take any space. The visibility: hidden property hides the element but still keeps its space in the layout. The opacity: 0 property makes the element fully transparent, meaning it becomes invisible but still stays in its place and can even be clicked unless we disable pointer events. These properties help us control how elements appear or disappear on a webpage.

Transformations

In CSS, there are functions used to transform elements:

  • rotate() – Rotates an element around a fixed point.
  • scale() – Resizes an element, either making it larger or smaller.
  • skew() – Tilts an element to the left or right.
  • translate() – Moves an element from one position to another on the screen.

These functions help you change the appearance and position of elements dynamically.

3D Transformations

You just learned about 2D transformations. Now, let's move on to 3D transformations. In 2D, we can move an element along the horizontal (X) and vertical (Y) axes. In 3D, we can also move it along the Z-axis. The Z-axis adds depth, allowing us to bring the element closer to us or push it farther away.

To control this depth, we use the perspective function, which defines the distance between the viewer and the object. There is also a transform-origin property that sets a fixed point on the element around which it rotates, similar to how a ceiling fan rotates around its center or a car wheel spins around its axis.

      transform: perspective(100px) translateZ(200px);
}

      transform: perspective(200px) rotateZ(45deg);
}

.box2:hover{
      transform: perspective(200px) rotateY(70deg);

      Set Origin of the box based on X and Y axis.
      transform-origin: 0 0;

      transform-origin: 0 50%;
}

What if we have multiple elements? There is a perspective property that allows us to give a single perspective to each element. Now, let's wrap two <div> elements inside a container or parent element to group them together.

If we want to apply different transformations to each child, or if we want all children to share the same perspective, we should use the perspective property on the parent element instead of using it inside the transform function for each child.

Transitions

Transitions are used to make changes between two states of an element happen smoothly instead of instantly. For example, if an element transforms from its first state to its last state, a transition defines how long and in what way this change should occur.

Transitions are used to make changes between two states of an element happen smoothly instead of instantly. For example, if an element transforms from its first state to its last state, a transition defines how long and in what way this change should occur.

Here’s how transitions work:

  1. Property – First, we specify which property or properties the transition will apply to. You can target a single property, multiple properties, or use the keyword all to apply the transition to everything.
  2. Duration – Next, we set how long the transition should take (in seconds or milliseconds) to go from the initial state to the final state.
  3. Timing Function – This defines the speed curve of the transition. For example, it can start slow and end fast, or move at a constant speed. We can use predefined functions like linear, ease, ease-in, ease-out, or create custom curves using cubic-bezier. A helpful tool for this is cubic-bezier.com ,where you can experiment and copy the generated values.
  4. Delay – This optional value sets how long to wait before starting the transition.

You can animate one property or multiple properties at the same time using transitions.

<div class="box"></div>

.box{
      width: 200px;
      height: 200px;
      background: red;

      transition: transform  0.5s, background 1s;
}

Animations

Transitions vs. Animations in CSS:

  1. Transitions are used for simple, smooth changes of properties, like changing color, size, or position when an element is hovered or clicked. They are best for simple effects.
  2. Animations are used for more complex or continuous effects. Unlike transitions, animations can play automatically without user interaction.
  3. CSS animations are created using @keyframes, which defines the frames of the animation. Just like a movie, which is made of multiple frames, CSS animations consist of multiple steps.
  4. Naming Animations: After @keyframes, you give your animation a meaningful name to identify it.
  5. Defining Animation Steps: There are two ways to define animation frames:
    1. from and to keywords: from represents the start state, and to represents the end state.
    2. Percentage (%) values: For multiple steps in an animation.
      • 0% = first frame
      • 50% = middle frame
      • 100% = last frame

This lets you control how an object changes over time, performing multiple actions during the animation duration.

  • Animation Properties in CSS:
    • animation-direction → Controls the direction of the animation (normal, reverse, alternate).
    • animation-fill-mode → Determines how the element retains styles before and after the animation.
    • animation-iteration-count → Sets how many times the animation repeats.
  • The choice of properties and steps depends on how complex you want your animation to be and how many changes you want to make during it.
@keyframes ncs{
      0%{
        transform: scale(1);
      }
      25%{
        transform: scale(1.5);
      }
      50%{
        transform: rotate(90deg);
        background: black;
      }
      100%{
        transform: rotate(0);
      }
}

Reusable Animations

If you want to apply the same animation to multiple elements, the easiest way is to use shorthand syntax or a utility class. First, create a class for your animation. Then, to animate any element, simply add that class to it.

There are websites that provide ready-made CSS animations. One popular option is animate.style, Animista .
You can also search for "CSS animations" to find other tools. These websites show examples of how animations work.

To use an animation from such a website:

  1. Copy the CDN link provided by the website.
  2. Paste the link inside the <head> section of your HTML document.
  3. Copy the animation class you like.
  4. Add that class to any HTML element you want to animate.

By doing this, you can easily reuse the same animation across multiple elements without writing the animation code from scratch. 

HTML Head
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css">

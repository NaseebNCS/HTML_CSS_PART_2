TYPOGRAPHY

What we Will Learn?

Welcome to the next section of HTML & CSS Part 2! This section is all about Typography, which is the art of creating beautiful and easy-to-read text. We will discuss styling fonts, embedding custom fonts, using font services, and best practices for text sizes and spacing both vertical and horizontal. We’ll also cover how to properly format text.

This topic is extremely important because almost 90% of a website’s content is text, so you must ensure your text is readable and looks great on all screen sizes. Let’s get started!

Styling Fonts

To change the font style on a webpage, we use the font-family property. There are three main categories of fonts used on the web:

  1. Serif
  2. Sans-serif
  3. Monospace

There are more font categories, but they are mostly used in printing and are not very common on the web.

Serif fonts have small decorative strokes at the ends of their letters. Because of these strokes, serif fonts look more traditional, professional, and serious. They are often used in books, magazines, and newspapers. Popular serif fonts include Georgia and Times New Roman.

Sans-serif fonts do not have those strokes. “Sans” means without. These fonts look clean, modern, and easy to read on screens. Popular sans-serif fonts include Avenir, Arial, Futura, Helvetica, Roboto, and many others.

Monospace fonts give every character the exact same amount of horizontal space. “Mono” means one, so each letter takes one equal space. These fonts are commonly used for displaying code because they keep everything aligned neatly. Popular monospace fonts include Consolas, Courier, and Ubuntu Mono.

The font you want to apply to most elements should be set on the body. You can always override it later for specific elements. 

p{
      font-family: roboto;
}

Web Safe Fonts

After typing font-family and pressing Ctrl + Space, VS Code suggests some fonts. These are called web-safe fonts because they are available on most devices, which makes them safe to use in your designs.

Font Stack

Fonts are separated with commas, and this is called a font stack. A font stack is a list of similar fonts or fonts from the same family. The browser checks the stack from left to right:

  • It tries to load the first font.
  • If the user’s device does not have that font installed, it moves to the next font in the list.
  • The last font is usually a generic font family (like serif, sans-serif, monospace).

This way, we give multiple options, and the browser decides which font to use based on availability. 

body{
        font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
    Oxygen, Ubuntu, Cantarell, "Open Sans", "Helvetica Neue", sans-serif;
}

Font Weight

Font-weight is used to control how bold or thick the text appears. The values range from 100 to 900:

  • 100 = very thin
  • 900 = very thick

You can also use keywords:

  • Bold = 700
  • normal = 400

Using Ctrl + Space in VS Code helps you see all available values for the property.

p{
       font-weight: bold; 
       font-weight: 100; 
       font-weight: 500; 
}

Font Style & Size

font-style is used to change the style of the font. Its default value is normal, but you can set it to italic to italicize the text.

font-size is used to change the size of the text. There are many possible values, and you can press Ctrl + Space to see suggestions in most code editors.

p{
        font-style: italic; 
        font-size: 2rem;
}

Color & Accent Color

color is used to change the color of text or inline content, while accent-color is used to change the color of form controls such as radio buttons, checkboxes, range sliders, and other UI elements. 

h1{
        color: red;
}

input[type="checkbox"]{
        accent-color: red;
}

Embedding Fonts

Web-safe fonts are available on almost all devices, and while they are reliable, they can be pretty boring. These days, there are many websites where you can find beautiful fonts some free and some paid. One popular website is FontSquirrel.com, where you can find plenty of free, high-quality fonts.

Font Formats

  • TTF
  • OTF
  • EOT
  • WOFF
  • WOFF 2.0

You don’t need to memorize all the font formats, but you should know that fonts come in different formats just like images and videos have their own file types. For the web, we usually use WOFF and WOFF2, because these formats are highly compressed. Whenever you use custom fonts, always make sure their file size is as small as possible so they can download quickly.

Download

Download any font from FontSquirrel by searching for fonts like Roboto, Open Sans, etc. When you download it, you will get the font files in .ttf format. Inside the ZIP folder, you'll find multiple files each file represents a different variant of the same font (such as regular, bold, italic, etc.).

How to Use

You can install these fonts on your computer to use in applications like Word, Photoshop, and more. But for web pages, we need to convert these .ttf files into .woff or .woff2 formats, because TTF files are large in size and not optimized for the web. WOFF and WOFF2 are compressed web-friendly formats that load faster.

Converting Font Formats

Go to the same website FontSquirrel.com, and open the Generator tab. There you can upload the font file(s) you want to convert. Upload one or multiple files, accept the agreement, and download Your Kit.

These days, most browsers support WOFF, and modern browsers also support WOFF2. After downloading the kit, copy the WOFF and WOFF2 font files into your project.

@font-face

Inside the downloaded folder, you will find a stylesheet that contains the @font-face rules. These rules tell the browser where to find your font files. In the @font-face block, you’ll see properties such as font-family, font-weight, font-style, and src. The src property includes a fallback stack, meaning: if the browser can’t load the WOFF2 file, it will automatically try the WOFF file.

Copy & Rename

Now copy these @font-face rules and paste them at the top of your project’s stylesheet. Make sure to correct the file paths inside the src URLs to match the font location in your project.

You can rename the font-family to any custom name you prefer. You can also adjust font-weight values if your downloaded kit includes multiple variations (like Light, Regular, Bold) of the same font.

Flash of Unstyled Text

Let’s see this in action. Open your browser, go to Developer Tools, and click on the Network tab. First, disable the “Disable cache” option. Cache is a type of permanent storage the browser uses to store website assets. When we visit a website, the browser stores images, fonts, and other files in cache memory. Once we disable it, every time we refresh the page, all resources are downloaded from scratch.

Refresh

After refreshing the page, you will see all files being requested from the server in the Network tab. The .woff and .woff2 font files load in milliseconds because we are using our local fast machine. But what happens when a real user has a slow internet connection? We can simulate that.

Cache

Right next to the “Disable cache” checkbox, you’ll see the Throttling option. Change it from Online to Slow 3G (or Fast 3G). Now refresh the page again you will notice that the fonts take seconds to download. During this delay, the user sees the fallback font first and then suddenly sees the custom font appear. This sudden change is the Flash of Unstyled Text (FOUT).

FOUT

In large projects, FOUT can create a bad user experience because elements may shift when the custom font replaces the fallback font.

Font Display

There is a technique to reduce (but not completely remove) FOUT: using the font-display property in CSS. It has values like auto, swap, fallback, block, and optional.

  • swap Best practical option. Shows fallback font immediately, then swaps to the custom font once downloaded.
  • block Avoid this. It hides the text until the custom font loads. If the font never loads due to network issues, the text may never appear.
  • fallback Shows fallback font quickly and gives a smaller time window for swap.
  • optional Tells the browser: the custom font is nice to have but not critical. If the font loads fast, it will be used; otherwise, stick to the fallback. This avoids layout shifts.

Once the font is downloaded, navigating to another page or refreshing will use the cached version, so the shift won’t appear again.

Expert Settings

If you use FontSquirrel, there are additional settings under “Expert Settings” that help reduce font size. You can even use the custom sub-settings to include only the characters you need, which further reduces file size.

Font Services

Now we know how to use custom fonts, but some fonts need to be licensed, and licenses can be quite expensive. This is where font services help us. One of the most popular services is Google Fonts, which gives you access to tons of free fonts. All fonts on Google Fonts are free to use in personal and commercial projects.

Paid Fonts

There are also paid font services such as Adobe Fonts, Fonts.com, Fontdeck, and others. Most of these services work on a subscription model, where you pay a monthly or yearly fee to access thousands of high-quality fonts. Paid fonts usually look more premium and polished, so if you have the budget, you can use them. Otherwise, free fonts are more than enough for most projects.

Free Fonts

To explore free fonts, visit fonts.google.com. You will find many fonts there, and you can search or filter by categories. Spend some time (around 20–30 minutes) exploring the options, and you will become familiar with how it works. For example, search for Open Sans. You will see different font weights and styles such as 400, 700, 900, etc.

After selecting a font, click the “Get font” button at the top right. You will see two main options:

  • Download the font files
  • Embed the font for online use

When using fonts online, Google Fonts provides two embedding options:

  • An HTML <link>
  • A CSS @import

If you copy the HTML <link> and paste it into your project, you will notice that it contains two links:

  • One for faster connection
  • One that loads the font service

If you open the link of href value in a browser, you will see many CSS rules. These rules are loaded automatically from Google, so we don’t need to write them manually. At the bottom where you copied the link in Google Fonts page, you will find the font-family name, which you just need to copy and paste into your CSS.

Query

If you look closely at the link from fonts.googleapis.com, the part after the ? is called a query string. Query strings contain parameters, written using an = sign.

  • family is a parameter name
  • The value after = is the parameter value

The + symbol represents a space, because spaces are not allowed in URLs.

If you select multiple font families, you will see the & symbol, which is used to separate multiple parameters.

This means:

  • If you only want one font, you can remove the extra parameters after the &
  • If you want more fonts or values, you can add them using the same format

Watch Closely the following link you will find all these operators:

HTML
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin<
<link href="https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Bitcount+Prop+Single:wght@100..900&family=Geom:ital,wght@0,300..900;1,300..900&family=Roboto+Condensed:ital,wght@0,100..900;1,100..900&family=Roboto:ital,wght@0,100..900;1,100..900&family=Sekuya&display=swap" rel="stylesheet">

CSS
@import url('https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Bitcount+Prop+Single:wght@100..900&family=Geom:ital,wght@0,300..900;1,300..900&family=Roboto+Condensed:ital,wght@0,100..900;1,100..900&family=Roboto:ital,wght@0,100..900;1,100..900&family=Sekuya&display=swap');

System Font Stack

Another way to apply fonts is by using the system font stack. With a system font stack, we tell the browser to use the default fonts of the user’s operating system and device.

This approach has several benefits.
The first and biggest benefit is performance. Since the browser does not need to download any external font files, the website loads faster. This also means users will not experience issues like FOUC (Flash of Unstyled Content), FOIT (Flash of Invisible Text), or layout shifting caused by font loading.

Another benefit is familiarity. The website feels more natural and comfortable to users because it uses the same fonts they already see on their own system. Overall, this results in a better user experience.

However, there is one important thing to understand: each operating system uses a different default font.

For example:

  • Recent versions of macOS use a different system font than older versions
  • Windows has its own default system font
  • Android devices use a different system font as well

You don’t need to memorize all these fonts, but you should know that different operating systems have different system fonts. Because of this, using a system font stack means your website may look slightly different from one computer or device to another.

In the past, web-safe fonts were commonly used, but they often looked outdated and boring. System UI fonts, on the other hand, are modern, clean, and visually appealing.

To use the system font stack, simply use the font-family property. You can press Ctrl + Space (or your editor’s suggestion shortcut) and select system-ui, or you can manually type: 

body{
      font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
    Oxygen, Ubuntu, Cantarell, "Open Sans", "Helvetica Neue", sans-serif;
}

This is a simple and powerful way to improve both performance and user experience.

Sizing Fonts

We already know that we can change text size using the font-size property. Font sizes can be defined using absolute units like px or relative units like rem.

Avoid px

We should avoid using px because pixels are not consistent across different devices. For example, Apple devices use high-density screens where pixels can be scaled to appear smaller and sharper. This technology is known as Retina Display.

As a result, text defined in pixels may appear smaller on some devices (such as Windows screens) and larger on others, which creates inconsistency. To solve this problem, we should always prefer relative units like rem, which we have already covered in previous lectures.

Type Scale

There is also a tool called Type-Scale that helps you choose appropriate font sizes for headings and text. On the left side, you can adjust the settings to match your project’s requirements. This tool is very useful for getting the correct and visually balanced sizes for your headings and typography.

Vertical Spacing

We have covered everything we need to know about fonts. Now, let’s learn about text properties.

Here are two important properties used to control vertical spacing: margin and line-height.

Law of Proximity

If we insert a heading and a paragraph multiple times with the same spacing, it can break a design rule called the Law of Proximity. The Law of Proximity states that objects placed closer together are perceived as related. This principle explains how humans visually understand relationships between different elements.

If elements are close to each other, they are perceived as belonging together. In our case, the heading has the same margin above and below, which makes it unclear whether the heading belongs to the content above or below it.

This is where we apply the Law of Proximity correctly. We should increase the top margin of the heading to separate it from the previous paragraph and reduce the bottom margin to bring it closer to its related content. This creates a clear visual relationship between the heading and the paragraph that follows. 

h1{
      margin: 3rem 0 1rem;
}

The top margin should usually be greater than the bottom margin to create better visual spacing.

Line Height

line-height is used to define the height of each line of text. It controls the vertical space between lines, allowing us to bring lines closer together or move them farther apart.

A common typographic rule is to set the line height to one and a half times the font size. For example, if the font size is 1rem, the line height would be 1.5rem.

You can use different values depending on what looks best on your webpage, so make sure to experiment with different numbers to achieve optimal readability.

body{
      font-size: 1rem; 
      line-height: 1.5rem;
}

Problem with Line-Height

There is a problem with this approach: if we increase the font size in the future, the line-height will not scale with it and will no longer look the same.

We can solve this by removing the unit from the line-height value. For example, instead of using 1.5rem, we use 1.5.

A unitless line-height works as a multiplier, meaning it will always be 1.5 times the font size, no matter what the font size is. This keeps the spacing consistent and responsive.

body{
      font-size: 3rem; 
      line-height: 1.5;
}

Horizontal Spacing

There are three properties used for horizontal spacing in CSS:
letter-spacing, word-spacing, and width.

letter-spacing is used to control the space between letters in text.
With letter-spacing, we usually use pixel values such as 1px, 2px, etc.
We can also use negative values, but this depends on the font being used and how you want the text to appear visually.

word-spacing is used to control the space between words in a sentence.

h1{
      letter-spacing: -1px;
}

p{
      word-spacing: 4px;
}

Ideal Line length

How many characters should a line contain for comfortable reading?

Research shows that the ideal line length is between 50 and 70 characters per line. When a line exceeds 70 characters, reading becomes more difficult because the reader’s eyes have to travel too far from left to right and then find the start of the next line again. This breaks reading flow and causes fatigue.

On the other hand, if a line contains too few characters (for example, one or two words per line), the text becomes excessively tall, forcing the reader to scroll too much and making the content feel overwhelming.

That’s why maintaining a balanced line width is important. A width of 50–70 characters keeps the text readable, scannable, and visually comfortable.

To control line length in CSS, we often use the ch unit. The ch unit is relative to the width of the “0” (zero) character in the current font.
For example, 50ch means the width of 50 zero characters.

Keep in mind that not all characters have the same width. Characters like i or 1 are narrower, while others take more space. Because of this, 50ch usually results in about 50–60 readable characters, which fits well within the ideal line-length range.

p{
      width: 50ch;
}

Formatting Text

There are many CSS properties used to format text, such as text-align, text-indent, text-decoration, text-transform, white-space, column-*, and direction (used for right-to-left languages like Arabic and Pashto).
There are many more text-formatting properties available, and you can explore them as needed.
However, these are the essential properties that every front-end developer must know. 

h1{
      text-align: left;
      text-align: center;
      text-align: right;
}

p{
      Not recommended, makes your text hard to read by dividing the remaining space between words
      text-align: justify;
}

we don't want to indent the first paragrpah right after the heading, but after the first paragraph we want indentation for that we can use the relational selector. 

p + p{
      text-indent: 2rem;
}

Text Decoration

Text decoration includes multiple properties such as line, thickness, and color. These can be written using a shorthand property, or you can define each property separately. 

p{
      text-decoration: underline;
      text-decoration: 3px line-through red;
}

Change Case

To change text case there is used text-transform property. 

p{
      text-transform: lowercase;
      text-transform: uppercase;
      text-transform: capitalize;

      Used with Capitalized Case for headings
      text-variant: small-caps;
}

Text Wrapping

To control the text wrapping there is used white-space property. 

p{
      white-space: nowrap;
}

text-overflow

If you want to hide overflowing text, you can use overflow: hidden.
However, if you want the text to continue but be shortened visually, you can truncate it.
For this, we combine overflow: hidden with text-overflow: ellipsis.
This displays dots (...) at the end of the first line to indicate that the text has been cut off.
Keep in mind that the width of the element must be fixed (or constrained) for text truncation to work properly. 

p{
      width: 50ch; 
      white-space: nowrap;
      overflow: hidden; 
      text-overflow: ellipsis;
}

Text Columns

To divide your text in multiple columns we gonna use column property. 

p{
      Create Columns
      column-count: 2;
      column-gap: 1rem;

      Line Between Columns
      column-rule: 3px dotted red;
}

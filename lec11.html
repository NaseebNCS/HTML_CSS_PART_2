GRID

What is Grid?

Flexbox is a one-dimensional layout system. We use Flexbox to arrange multiple elements either in a row or in a column. But sometimes we need to place elements in both rows and columns at the same time. That’s where CSS Grid is used. A common example of Grid is a photo gallery, where we can create multiple rows and columns easily. Grid is also widely used to create full webpage layouts.

Grid Container

To create a CSS Grid, we first need a container. In that container, we set display: grid. To define the layout, we use grid-template-columns to create columns and grid-template-rows to create rows. In HTML, we simply create a <div> with a class like container and apply these grid properties in CSS. 

HTML
<div class="container"></div>

CSS
.container{
        border: 3px solid lightgrey;
        Grid Properties for container
        display: grid;
        3 x 2 layout
        grid-template-rows: 100px 100px 100px;
        grid-template-columns: 100px 100px;
}

DevTools & Repeat Function

In the browser’s DevTools (Inspect), you will find a tab called Layout. Inside the Elements panel, when you select a container that uses CSS Grid, you will see a Grid label. Clicking on it will toggle the grid overlay on your page. In the Layout tab, you can adjust various grid-related settings such as track sizes, showing area names, and extending grid lines. At the bottom of the same tab, you will find the Grid Overlays section, where you can change the grid’s color as it appears in the browser.

While creating rows and columns, we have different types of units and functions we can use. For example, if multiple columns or rows have the same size, we can use the repeat() function instead of writing the same value multiple times. 

.container{
        columns number, size
        grid-template-rows: repeat(3, 100px);
        grid-template-columns: repeat(2, 100px);
}

Grid Template

There is another property called grid-template, which is the shorthand for grid-template-rows and grid-template-columns. In this shorthand, we write the rows first, then a forward slash /, and then the columns. 

.container{
        rows / columns
        grid-template: repeat(3, 100px) / repeat(2, 100px);
}

let's create items for grid in html, multiple divs inside the container box. 

HTML
<div class="container">
    <div class="box box1">A<div>
    <div class="box box2">B<div>
    <div class="box box3">C<div>
    <div class="box box4">D<div>
</div>

CSS
.container{
        border: 3px solid lightgrey;
        grid-template: repeat(3, 100px) / repeat(2, 100px);
}

.box{
        width: 5rem;
        height: 5rem; 
        background: gold; 
}

Grid Alignments

By default, grid items are placed from top-left to bottom-right, but we have full control over their positioning. Just like in mobile layouts where we move elements as needed, CSS Grid also works with two axes:
the horizontal axis and the vertical axis. For alignment, we use justify-items to align items along the horizontal axis, and align-items to align items along the vertical axis. Now, let's align the items. 

.container{
          Must Enable the grid feature in dev tools for clearity
          justify-items: center;
          align-items: center;

          Container Alignment
          justify-content: center; container horizontal alignment
          height: 100vh;
          align-content: center; Container vertical alignment content is for grid container and items for grid items 
}

The default value of justify-items and align-items is stretch. This means if your grid items don’t have a fixed width or height, they will automatically stretch to fill the available space inside the container. So, if you remove the width and height from the items, the boxes will stretch and fill the grid cells based on the row and column sizes.

Grid Units

There are different units you can use for grid columns and rows, like percentages (%). Percentages depend on the width of the container, but they can be tricky to manage. Instead, you can use fr (fractional units), which divide the available space evenly or proportionally among the columns and rows.

For example, if you set the first column to 30% and the second to 70%, it will fill the full width of the container. But if you add another column with a fixed value like 100px, the layout may overflow. To avoid this, you can use the auto keyword, which automatically takes the remaining space after fixed-sized columns. There is also the gap property, which is used to add space between rows, columns, or grid cells. 

.container{
          Units for Grid columns and rows
          grid-template: repeat(3, 100px) / 30% 70%;
          
          Problem is
          grid-template: repeat(3, 100px) / 100px 30% 70%;
          
          Using FR to solve the problem
          grid-template: 100px auto 100px / 30fr 70fr;

          row-gap: 10px; 
          column-gap: 10px;
          ShortHand
          gap: 10px;
}

Grid Items

Placing grid items is done using three main properties: grid-row, grid-column, and grid-area. These properties belong to grid items, and by using them, we can control exactly where an item should be placed inside the grid.

For example, if we want the first item to take up the entire row or span multiple rows and columns, we can set these properties accordingly. In the browser’s DevTools grid layout tab, you’ll notice line numbers for each row and column. If a grid has 2 rows, it will have 3 horizontal grid lines. Similarly, if there are 5 columns, it will have 6 vertical grid lines. These line numbers are used to position and stretch items using grid-row and grid-column values.

.box1{
          Move first Item to second column
          grid-column: 2;
          
          Expand Item
          grid-column: 1 / 3; 3 lines
          
          Expand to the last
          grid-column: 1 / -1;
          
          If Spaning by row and column numbers
          grid-column: 1 / span 2; 2 columns
          
          
          Move first Item to second row
          grid-row: 2; 

          Expanding cell size to take 2 rows height
          grid-row: 2 / 4; row line number 4
          grid-row: 2 / span 2; row number 2
}

Note: grid-column is the shorthand of grid-column-start and grid-column-end, same for the row.

Grid Area

There is another property called grid-area, and it uses a different syntax. It allows you to define the start row, start column, end row, and end column. For example, if we want the first item to span 2 columns and 1 row, then it will start at row 1, column 1, and end at row 1, column 3. Column 3 means the item is covering two columns (from column 1 to column 3). 

.box1{
          grid-area: row-start / column-start / row-end / column-end;

          Shorthand of grid-column and grid-row
          grid-area: 1 / 1 / 1 / 3;
                         r1  c1  r1  c3
}

Understanding grid-template-areas and grid-area with empty cells:

Another way to place items in a grid is by using grid-template-areas along with grid-area. This allows you to name areas of the grid and assign items to those names. You can also use a period (.) in grid-template-areas to create empty cells where no item will be placed.

For example, imagine we want a layout with a header, sidebar, main content, and footer: 

.container {
          display: grid;
          grid-template-columns: 150px 1fr;
          grid-template-rows: 50px 200px 50px;
          grid-template-areas:
            "header header"
            "sidebar main"
            "footer footer";
          gap: 10px;
}

.header { 
          grid-area: header; 
}
.sidebar { 
          grid-area: sidebar; 
}
.main { 
          grid-area: main; 
}
.footer { 
          grid-area: footer; 
}

Here:

  • "header header" > header spans 2 columns
  • "sidebar main" > sidebar in first column, main content in second column
  • "footer footer" > footer spans 2 columns

If we want an empty cell in the second row, we can use a period (.):

.container{
        grid-template-areas:
            "header header"
            "sidebar ."
            "footer footer";
}

Now, the second column in the second row is empty.

Tip:

In modern browsers’ web dev tools, there’s a Layout tab (or Grid Inspector). It shows your grid visually with area names so you can see exactly how each item is placed.
